### IMS — Tray QR (`tray_code` + `id`)

Same public-URL pattern as box stickers. Label **50×25 mm** (IMS, not RM Store inch size).

| Item | Detail |
|------|--------|
| Print URL | `?tray_code=FG101&id=<primary_id>` via `resolveTrayQrPayload` (`publicQrUrl.js`) |
| API | `POST /api/trays/qr-payloads` body `{ trays: [{ id, code }] }` |
| Scan | Prefers **id**, then code — `resolveTrayScanCode` (FE) / `normalizeTrayScanCode` (BE) |
| Safety | Box/coil/FN `id=` alone is **not** tray; need `tray_code` (or `tray`) on same URL |
| Legacy | Code-only QR (`FG…`) still works |

**Files:** `publicQrUrl.js`, `trayScanParse.js`, `trayMaster.controller.js`, `qrScan.js`, `publicQrScanValue.js`, `trayQrLabel.js`, `trayQrPrintSize.config.js`, `locationQrLabel.js`, `tray.js`, `InwardModal.js`

Also in [v5.2.0.md](./v5.2.0.md) (27 Oct).
