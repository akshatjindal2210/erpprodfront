## v4.4.7 — HRMS Leave · HRMS Loan · Daily Attendance day-wise default

### 5 Oct 2026

**Summary.** HRMS mein **Leave** aur **Loan** modules Gate Pass pattern pe add kiye (simple tables, Sup → HR approve, IMS-style list/drawer). Employee naam/dept request table mein store nahi — `emp_dcode` + ERP master JOIN. Leave: overlap + past date block, CL/SL/PL. Loan: type loan/advance, EMI compute (schedule table nahi), ek time pe ek pending. **Daily Attendance** pe From/To by default **sirf aaj (1 day)**; baaki modules ka date span pehle jaisa. Gate Pass / Attendance core flow nahi tode.

| Topic | Summary |
|-------|---------|
| **Leave** | New module `hrms_leave` — request → Supervisor → HR |
| **Loan** | New module `hrms_loan` — Loan + Advance, same approve flow |
| **Tables** | `hrms_leave`, `hrms_loan` — CREATE IF NOT EXISTS, light indexes |
| **UI** | ServerListPage + Drawer, IMS buttons, hotkeys, filters |
| **Attendance dates** | `dateDefaultSpanDays={1}` only on Daily Attendance |
| **Permissions** | Seed modules `hrms_leave`, `hrms_loan` (view/add/edit/authorize/delete) |

## 1. HRMS Leave

### Behaviour

| Step | Result |
|------|--------|
| Create | Employee + type (CL/SL/PL) + from/to + reason |
| Days | Auto (inclusive calendar days) |
| Past date | Block (from/to ≥ today IST) |
| Overlap | Same emp + overlapping dates → block |
| Clear employee | Form reset |
| Approve | Supervisor (`edit`) then HR (`authorize`) — stamps like Gate Pass |
| Status | Computed: `pending_manager` → `pending_hr` → `approved` |
| Delete | Hard delete (Gate Pass jaisa) |
| Balance / half-day / remarks | Nahi (simple rakha) |

### Table `hrms_leave`

```
id, emp_dcode, leave_type, from_date, to_date, days, reason,
sup_by, sup_at, hr_by, hr_at,
created_by, updated_by, created_at, updated_at
```

Index: `emp_dcode`.

### API (`/hrms/leave`)

| Route | Permission |
|-------|------------|
| `POST /list` | view |
| `POST /submit` | add |
| `POST /update` | edit |
| `POST /verify/manager` | edit |
| `POST /verify/hr` | authorize |
| `POST /delete` | delete |

## 2. HRMS Loan (Loan + Advance)

### Behaviour

| Step | Result |
|------|--------|
| Type | `loan` or `advance` |
| Advance | `emi_months` forced = 1 |
| EMI | `amount / emi_months` (store nahi); schedule view pe compute |
| Pending rule | Ek emp pe ek hi pending (not fully approved) |
| Approve | Supervisor → HR (Gate Pass jaisa) |
| Repayment table | Nahi (baad mein agar payroll chahiye) |

### Table `hrms_loan`

```
id, emp_dcode, type, amount, emi_months, start_month, reason,
sup_by, sup_at, hr_by, hr_at,
created_by, updated_by, created_at, updated_at
```

## 3. Daily Attendance — day-wise default

### Rule

| Page | From / To default |
|------|-------------------|
| **Daily Attendance only** | Today → Today (`dateDefaultSpanDays={1}`) |
| Other list pages | Pehle jaisa (list-view span / view-days) |

User date / User / **Shift** (Day A / Night B) filter se aur dekh sakta hai. Night shift `attendance_date` pehle se backend rule se handle.

### Key files

| Path | Change |
|------|--------|
| `frontend/src/apps/hrms/modules/attendance/Page.js` | `dateDefaultSpanDays={1}` |
| `frontend/src/ui/common/list/ServerListPage.js` | optional prop `dateDefaultSpanDays` |
| `frontend/src/ui/common/list/dateFilterDefaults.js` | override support for forced span |
