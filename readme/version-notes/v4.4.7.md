## 3b. Daily Attendance — Day / Night / Hours / OT

**Formulas live at the top of:** `backend/src/apps/hrms/lib/attendanceCommon.js`  
**UI display only:** `frontend/src/apps/hrms/lib/attendanceUtils.js` → `hoursFromApi()` / `formatDuration`  
Change rules only in `attendanceCommon.js`. Frontend must not recompute OT/Adjust.

### Cutoffs (IST)

| Constant | Value | Meaning |
|----------|-------|---------|
| `NIGHT_SHIFT_FROM` | **17:00** | First punch ≥ this → Shift **B** (night) |
| `NIGHT_SHIFT_END` | **08:00** | Next-morning Out window ends; after this → force Out |
| `LUNCH_THRESHOLD_MINUTES` | **240** (4h) | Punch span ≥ 4h → lunch on |
| `LUNCH_MINUTES` | **30** | Deducted from Total → Worked |

### Case 1 — Day shift (A)

First eligible punch **before 17:00** (and ≥ 08:00 that day).

Example: In **08:15**, Out **18:30** (same calendar day).

| Step | Result |
|------|--------|
| First punch &lt; 17:00 | Shift **A** |
| In | First eligible punch that day |
| Out | Last punch **same day** (if ≥ 2 punches) |
| Default In / Out | TIMESTAMPTZ on that `attendance_date` (from emp master times) |

### Case 2 — Night shift (B)

First eligible punch **≥ 17:00**.

Example: In **01 Oct 20:13**.

| Out situation | System result |
|---------------|---------------|
| Next morning **before 08:00** (e.g. 07:03) | That punch = **Out** |
| Next morning **≥ 08:00** (e.g. 09:00), or no morning punch | **Out forced to next day 08:00** |
| Same-day punch before 08:00 | Ignored for this date (previous night’s Out) |

If Out is forced, the user/HR can **Edit** Daily Attendance and correct times.

### Hours / OT (columns on `hrms_attendance`)

| Field | Meaning |
|-------|---------|
| `total_minutes` | In → Out (was `punch_minutes`) |
| `lunch` | Boolean — Total ≥ 4h → true (30 min deducted) |
| `worked_minutes` | Total − lunch |
| `default_in` / `default_out` | TIMESTAMPTZ; night Out on **next day** when needed |
| `ot_minutes` | **Full (FD):** extra after default Out **> buffer** → full extra; **1..buffer** → OT **0** + **Adjust** = extra; else both **0**. Never negative. **Half (HD):** excess over Normal (no buffer, Adjust 0) |
| `adjust_minutes` | FD leftover extra inside buffer when OT is 0 (hidden in UI when 0) |
| `ot_approved` / by / at / remarks | +OT → pending (`0`); −OT → **System** auto (`1`) |

Removed column: `punch_count`.

### OT buffer (`hrms_overtime_buffer_minutes`)

Grace minutes after default Out before positive OT counts (Full day only).

| Item | Detail |
|------|--------|
| Config key | `hrms_overtime_buffer_minutes` |
| Allowed | **10–120** minutes |
| Default | **30** |
| Formula (FD) | Extra after default Out **> buffer** → OT = **full extra**, Adjust **0**. Extra **1..buffer** → OT **0**, Adjust = extra (no −3). Extra **≤ 0** → both 0 |
| Half day | Buffer not used — OT = excess over Normal only; Adjust 0 |
| UI setting | Settings → App Configuration → **HRMS** → “Overtime buffer (minutes)” |
| Loaded on | Attendance list / save / approve / `/calc` (`getHrmsOvertimeBufferMinutes()`) |
| Passed to FE | API field `overtime_buffer_minutes` + minute fields → drawer `hoursFromApi()` |

Example (buffer 30): Out 18:45 vs default 18:00 → extra **45 > 30** → OT = **45**, Adjust **0**. Out 18:25 → extra **25** → OT **0**, Adjust **25**. See examples A–D in `attendanceCommon.js`.

## 7. Follow-up (6 Oct 2026) — Attendance hours: backend-only · `/calc` · Adjust · FD/HD

One formula file: `backend/src/apps/hrms/lib/attendanceCommon.js` (examples A–D at top). Frontend never copies OT/Adjust math.

### `day_type`

Stored/displayed **FD** / **HD** (not Full / Half). `dayTypeDisplay()` returns those codes.

### OT + Adjust (Full day, buffer default 30)

| Extra after default Out | OT | Adjust |
|-------------------------|----|--------|
| `> buffer` | full extra minutes | 0 |
| `1 … buffer` | **0** (never −3) | those leftover minutes |
| `≤ 0` | 0 | 0 |

Half day: OT = excess over Normal; buffer and Adjust unused.

Late **In** has no penalty. Default In/Out come from employee master on that `attendance_date`.

### When `/attendance/calc` runs

`POST /hrms/attendance/calc` — Add/Edit **preview only**. Debounce **200ms**. Skip if In or Out empty, or same `hoursKey` (in/out/shift/day).

| Action | `/calc`? |
|--------|----------|
| Manual / Automatic **Load** | No |
| List / View / Approve open | No (`formatRow` computes in the list/view API) |
| Add: employee pick (search or row) with default In+Out | Yes — that row |
| Add: Shift / Day / In / Out change | Yes — that row |
| Edit single: Shift / Day / In / Out | Yes — `requestManualHours` |
| **Submit / Save** (1 or bulk) | **No** — body is emp + shift + day + in + out only |

Save: `submitAttendance` → each row `saveAttendanceRow` → `withOtFields` → `computeAttendanceDerived` → minutes written to DB.

List vs View mismatch (stale DB OT): `formatRow` **always** recomputes live derived fields; do not trust old stored `total_minutes` / `ot_minutes` for display.

### Drawer UI

| Surface | Hours |
|---------|--------|
| Add table | Total / Lunch / Normal / OT short; **Adjust** only if `> 0` (sky value); no Default block |
| View / Edit / Approve | Working Hours + Default In/Out (+ minutes); labels grey, values coloured |
| List | `attendanceColumns` → `hoursFromApi` |

### Key files

| Layer | Path |
|-------|------|
| Formulas | `backend/src/apps/hrms/lib/attendanceCommon.js` |
| `/calc` + `formatRow` + submit | `backend/.../attendance/controllers/attendance.controller.js` |
