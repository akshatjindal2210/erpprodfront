
## v2.2.20

---

### User Permissions — Inactive modules missing from list

**Problem:**
- When creating or editing a user, the permissions list showed only Active modules.
- Inactive modules disappeared — permissions could not be set for them.

**Fix:**
- Backend: removed the `is_active` filter from `getModulesViews` — all modules now appear in helper views.
- Frontend: `shouldIncludeInUserPermissionForm` always returns true — both Active and Inactive modules appear in the form.

**Files:**
- `backend/src/apps/core/controllers/module.controller.js`
- `frontend/src/config/moduleAppRegistry.js`
