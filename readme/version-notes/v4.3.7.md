### RM Store Stock Adjustment — Old type coil breakdown

When **Type = Old** and a financial year is loaded, the MRN search calls IMS with `requestedData: "mrn_rm_old"`. The response includes a `coils` field—a JSON string of per-coil quantities.

The app parses `coils` and pre-fills the breakdown: row count and per-row qty come from ERP; **Coils** and **Total qty** are read-only. Add (+) and Minus (-) stock-adjustment types are unchanged.

**Minus** (breakdown table) removes a coil row and reduces total qty by that coil’s ERP qty (e.g. 250 → 130 when 120 is removed). **Coils** shows the active row count (e.g. 1).

**Add** (+ next to Status) restores a removed coil with its original ERP qty, up to the ERP max (e.g. back to 130 + 120 = 250). Save submits only active coils; coil sum must match total qty.

### Create Deviation — schedule balance qty

The Create Deviation drawer shows three read-only qty pairs (Schedule, Shortage, FG Stock). They are informational only—they do not change the packing limit check or packing list data.

**Schedule / Balance Qty** — The balance is schedule qty minus qty actually dispatched on approved, non-deleted forwarding notes for the same item in the packing month (scanned box qty). A negative result is shown as 0.

This aligns the displayed balance with real dispatch rather than planned forwarding-note qty, so operators see remaining schedule capacity before raising a deviation.

| Field | First number | Second number |
|-------|----------------|---------------|
| Schedule Qty / Balance Qty | Item schedule qty for the packing month from the IMS schedule API | Schedule minus month dispatch (approved forwarding notes); minimum 0 |
| Shortage Qty / Balance Qty | Approved shortage for the item and month | Shortage minus qty already packed that month |
| FG Stock / Reorder Qty | Sellable in-hand FG | Reorder qty from the item master |

### MRN Portal — phone approve and stickers

Phone approve scan uses only the methods turned on in Device Settings (laser, keyboard, or phone QR). The scan field and QR button sit on one line. The camera stays open while multiple coil and QC codes are scanned, and closes only when the user taps close or when every required scan is done. The scanner overlay matches the IMS layout; the close control sits above the video so it receives the tap.

**New Sticker** is available for any non-rejected row. A pending row opens Generate. A row that already has stickers opens the saved sticker screen. Approve remains a separate action and still requires authorize permission.

On the reject drawer, No. of Coils can be cleared and typed again. The value is committed on blur, with a minimum of 1.

Sticker print is no longer limited to laptop. Phone print opens a preview, then Print.

### RM Rejection

MRN Portal rows show source **MRN PORTAL** only. The portal row id is not appended. Other sources (QC Fail, In-Process, Register) still show their ids.

The bill dropdown reads live bill numbers from IMS `invfnote` (the same dataset used by IMS bill lists). The previous `billno` key returned an empty list.

### Stock Adjustment — spec, documents, and header

Add (+) and Old cannot be created, updated, or approved unless an authorized RM Spec Master exists for the item. Save and Approve stay disabled, and the API returns 400 if the check is bypassed. Minus is unchanged, because it does not create coils.

Condition and Grade color badges appear in the header next to the MRN UID once the item is loaded. The item description is not repeated in that header row.

TC and RMTC documents are optional. Save succeeds without them. A file is uploaded only when one is selected.

### Phone print and preview

Hidden-iframe print does not open the system print dialog on phones. On a mobile device, print now opens a full-screen preview with Print and Close. Laptop print is unchanged.

The laptop-only block was removed for:

| Document | Where |
|----------|--------|
| Forwarding Note bill | IMS |
| Packing / box stickers | IMS |
| Coil and QC stickers | RM Store MRN Portal and Stock Adjustment |
| QC / coil report (bill) | RM Store |

Print routes still require the existing view or add permission. Restart the backend after this release so the old laptop-only check is no longer running.
