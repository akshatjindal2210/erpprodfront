## v3.4.32 — First RM Store production release *(20 Aug 2026)*

This is the **first dedicated RM Store** package on the **3.x** line.  
Coil is the stock unit. QC is required before Issue. Store In (rack) is optional.

|               |                               |
|---------------|-------------------------------|
| **UI**        | `/rmstore/`                   |
| **API**       | `POST /api/rmstore/…`         |
| **Gate**      | `app_rmstore`                 |
| **Frontend**  | `frontend/src/apps/rmstore/`  |
| **Backend**   | `backend/src/apps/rmstore/`   |

---

### End-to-end flow (simple)

```
ERP MRN (mrn_rm)
    → MRN Portal (generate coil / QC stickers)
    → Coils (unassigned / in store)
         ├─ QC Check (compulsory for issue)
         │     ├─ Pass  → Issue Request → Store Out (to shop floor)
         │     └─ Fail  → RM Rejection → Store Out (return)
         ├─ Store In (optional rack location)
         └─ In-process Request (floor: reject / store-in / consume / transfer)
Stock Adjustment can add / remove coils outside the MRN path.
```

---

### What each step does

| Step | Logic (simple) |
|------|----------------|
| **Masters** | Item↔RM map, QC specs, rack locations — setup before daily work |
| **MRN Portal** | Pull ERP MRN → create coils + print stickers (TC/RMTC optional) |
| **Coils** | Live coil list; Coil Finder = journey + QC + docs + print report |
| **QC Check** | Scan/inspect against RM Spec; approve pass or fail |
| **Store In** | Put coils on rack (location) |
| **Issue Request** | Reserve coils for job card / machine |
| **Store Out** | Scan coils out (job card or rejection return) |
| **RM Rejection** | Failed QC / IPR rejection register + bill |
| **In-process** | Shop-floor reject / return / consume / transfer |
| **Stock Adjustment** | Manual add / remove coil qty + stickers when needed |
| **Inventory / Logs** | Stock view + activity / coil / sticker download history |

### Important shared logic

| Topic | Where / what |
|-------|----------------|
| **Sticker design** | `lib/sticker/coilStickerDesign.js` — layout, QR, meta (`Created By` / `Timestamp`, align left/center/right) |
| **Coil Finder report** | `modules/coil/utils/coilFinderReport*` + FE `lib/finder/coilFinderData.js` |
| **Audit timestamps** | `lib/utils/sqlTimestampUpdate.js` — `NOW()` for approve/update/inspect (local time, not UTC ISO) |
| **QC status on coils** | `lib/utils/coilQcStatusSql.js` |
| **Approval workflow** | Shared `applyApprovalWorkflow` (authorize permission) |
| **Permissions** | Per-module `view` / `add` / `edit` / `authorize` / `delete` |
