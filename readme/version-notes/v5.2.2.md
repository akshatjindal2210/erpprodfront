### B. Board rules (FIFO + process machine)

| Rule | Where |
|------|--------|
| Running always top in column | `board.js` → `sortBoardColumn` / `BOARD_STATUS_RANK` |
| Same column: cannot reorder while Running | `Page.js` → `onBoardDragEnd` |
| Pending below Running can move to **another** machine | `Page.js` — Running card `dragLocked`; cross-column allowed |
| Target has Running → drop **below** Running | `Page.js` → clamp `newIndex` |
| Packing → only Packing M/C; Rolling → only Rolling M/C | `board.js` → `canMoveCardToMachine` / `allowedMachineIdsForCard` |
| Allowed M/C = JC `process_plan` machines ∪ Machine Master `macproccode` | same |
| Wrong process M/C on load → snap to JC preferred M/C + persist | `board.js` → `healCardMachineMismatch` in `fetchBoard` |
| Start only if FIFO allows | `board.js` → `canFifoAction` |
| Complete cards hidden on board (default) | `Page.js` → `visible` filter |

### C. Estimate time / Est end date

| Piece | File | How |
|-------|------|-----|
| Formula (cavity, cycle, setup → seconds → shifts) | `backend/.../jc/jobCardProductionTime.js` → `calcJobCardProductionTime`, `machineTime` | `shifts = ceil(time / SHIFT_HOURS)` |
| Per-machine shifts from estimate | same → `shiftsForMachine(est, maccode, stage_no)` | |
| Attach `est_shifts` on plan API rows | `plan.controller.helpers.js` → `attachEstShifts` | |
| Sync `plan_end` on JC authorize | `plan.model.js` → `syncPlanFromJobCard` | |
| Config: shifts/day, hours/shift | `frontend` + `backend` `.../jc/jobCard.config.js` | `SHIFTS_PER_DAY`, `SHIFT_HOURS` |
| Board card **Start · N shifts** | `Page.js` → `CardBody` uses `card.est_shifts` | |
| Board card **Est** (end date) | `Page.js` → `cardEstimateLabel` / `estimateDateFromShifts` | `plan_start` + shifts calendar; fallback `plan_end` |
| Cascade after DnD reorder | `board.js` → `cascadeColumnSchedules` | writes `plan_start` / `plan_end` |

```
Machine Master (cavity, cycle, setup) + JC qty
        → calcJobCardProductionTime
        → shiftsForMachine(this maccode)
        → card.est_shifts
        → Est date = Start + est_shifts (SHIFTS_PER_DAY)
```

**Behaviour**

- Create JC elsewhere (Authorize / Board); table = select row → View / Edit / Delete (`prod_plan` only).
- Default sort: `plan_start` **desc**.
- History button removed (page is listing).
- `TO_PLUS_1_MONTH`: `false` = To = today (IMS); `true` = To = today + 1 month.
