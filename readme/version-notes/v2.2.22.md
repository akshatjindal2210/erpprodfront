### PWA Push — Sent, Received, Read tracking

```bash
   Added:
      Har push notification ab 3 stages me track hoti hai — Sent, Received, Read.
      Admin → Settings → Notifications → Logs me ye 3 columns dikhenge.

   Sent:
      Server ne notification bhej di (Google FCM / Mozilla). Time: sent_at.
      User network se independent — ye server side hai.

   Received:
      Notification user ke phone par dikhi (tray / lock screen). Time: received_at.
      Koi bhi network chalega — mobile data, home Wi-Fi, office Wi-Fi.
      Logout ke baad bhi count hota hai (service worker device par chalta hai).

   Read:
      User ne notification tap kiya aur PWA open hui. Time: read_at.
      Sirf company network par count hoga.
      Home / mobile data se tap → Wi-Fi reminder page, read time save nahi hoga.

   Difference:
      Received = notification phone par aa gayi (koi bhi network).
      Read = user ne app open kiya (sirf company network).

   Flow:
      1. Server bhejta hai → status = sent
      2. Phone par dikhti hai → service worker report karta hai → status = received
      3. User tap karta hai → company network hai to read + app open | nahi to Wi-Fi reminder

   Logout:
      Logout par device subscription delete nahi hoti — logout ke baad bhi push aa sakti hai.
      Hatana ho to unsubscribe / unlink API use karo.

   Files:
      frontend/public/sw.js
      backend/src/apps/core/services/webPush.service.js
      backend/src/apps/core/models/pushDeliveryLog.model.js
      backend/src/apps/core/controllers/push.controller.js
```

### Company Wi-Fi check — Notification tap par

```bash
   Note:
      Notification receive karne ke liye company Wi-Fi required nahi hai.
      Ye check sirf tab chalta hai jab user notification tap karke app open karna chahta hai.

   Steps:
      1. Company backend ping (GET /api/version) — response aaya to app open.
      2. Ping fail ho to public IP match — match ho to allow.
      3. Dono fail → "Connect to company Wi-Fi" page → user connect kare → Try again.

   Received report alag hai:
      Koi bhi network par received report ho sakti hai.
      Offline ho to queue me rakhta hai, baad me bhejta hai.

   Bug fix:
      Pehle ping OK hone ke baad bhi wrong IP se block ho raha tha.
      Ab ping OK = directly allow.

   .env:
      PUSH_API_BASE_URL, PUSH_API_BASE_FALLBACKS, COMPANY_BACKEND_URL, COMPANY_PUBLIC_IP

   Files:
      sw.js, offline-vpn-reminder.html, companyNetwork.js,
      CompanyNetworkGate.js, webPushSubscribe.js
```
