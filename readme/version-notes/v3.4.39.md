### 11. Stock Adjustment Add — All Loose default, Full/Loose & packing no

**Problem:** Add defaulted to All Full; packing like `36618++` stayed on stickers; breakdown showed wrong kind (always Full) on pending/approve; Full/Loose did not match after save.

**Solution:**
- New Add defaults to **All Loose**
- **All boxes** dropdown on Add and Edit only (not View/Approve)
- Full/Loose stored in pending meta on `removed_box_ids` (no new SA column); approved boxes use **`ims_box_table.is_loose`**
- Breakdown shows correct **FULL / LOOSE** for pending rows from saved meta
- Any edit (including Full ↔ Loose) → **pending** → **Approve** again to apply
- Approve uses saved Full/Loose; pending meta cleared after add approve
- Packing no cleaned on load/blur (strip trailing `+`; prefer IMS `doc_no`) so stickers use `36618`

**Files:** `StockAdjustmentStickerCloneDrawer.js`, `StockAdjustmentApproveDrawer.js`, `stockAdjustmentViewBoxes.js`, `stockAdjustmentPacking.js`, `stockAdjustment.controller.js`, `stockAdjustmentSync.js`, `stockAdjustmentApply.js`, `minusRemovedBoxPayload.js`

### 12. CL Task Report — show tasks only when due

**Problem:** New CL tasks appeared in the report at create time (before the occurrence day). Future schedule days showed empty rows and affected period averages.

**Solution:**
- **Create:** no instance spawn — cron spawns when the occurrence day is due (same as My Tasks Due queue)
- **Report list:** `report_due_only` — only instances with `scheduled_date <= today`
- **Aggregated rows:** no row unless there is a due attempt or awaiting verification (future-only placeholders removed)
- **Frequent tasks:** day span and scores only for due/past days; future days stay blank until due
- **Period %:** average counts only days with stored `day_scores` / `day_states` (future days excluded)
- **Calendar grid:** cells only on due/past occurrence days or days with stored data
- **Scoring unchanged:** done → score % (or 100% without verify); pending → 0%; missed → 0%; awaiting verification → verification state

**Note:** After create, tasks may appear after the next hourly cron run (~:05). Re-activate still spawns immediately.

**Files:** `clTask.controller.js`, `clTask.model.js`, `reportPanel.controller.js`, `reportScore.helper.js`, `clTaskRecurrenceHelper.js`, `ReportBookingCalendar.js`
