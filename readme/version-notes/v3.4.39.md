### 1. Today Dispatch Plan — Recommended by Customer sort

**Problem:** Customer rows used Match % (weakest item). Operators want highest **total Rec. Dispatch Qty** first.

**Solution:**

| View | Top row |

| Recommended by Customer | Total Rec. Dispatch Qty ↓ (frontend `compareRecommendedCustomerRows`) |

### 6. FN save — IMS Ready schedule allowed

**Problem:** Save checked only local `schedule_plan`. Ready (IMS-only) lines showed in UI but save failed: *“not on the current schedule plan”* (error now shows **item code**, not dcode).

**Solution:** If plan DB miss → fallback to IMS `schdule` list. Exists on plan **or** IMS → OK.

**Why:** Ready filter is for dispatch without local Plan; FN must still save.

**Files:** `forwardingNoteItemsWrite.js`
