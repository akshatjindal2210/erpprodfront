### Out Entry approval recheck

Two draft forwarding notes could scan the same boxes. Approving the first moved those boxes out of stock, but the second draft still approved them.

`updateOutEntry` now rechecks live availability when `approved=true`. Unavailable boxes are removed from the draft, totals are recalculated, and the API returns `409` so the user can scan again and approve.

### ERP Stock Report — Adjust

On the mismatch view, a Super Admin can select one row and click **Adjust** (next to Refresh). Other users do not see the button or the row checkboxes.

Adjust posts the selected packing to the internal IMS API:

```json
{
  "requestedData": "stockadjust",
  "filter": {
    "docno": 17841,
    "docdt": "2025-10-11",
    "qty": 1970
  }
}
```

| Field | Source |
|-------|--------|
| `docno` | Packing number (digits only, so `11679+` is sent as `11679`) |
| `docdt` | Document date, `YYYY-MM-DD` |
| `qty` | Balance Stock (DB − ERP), sent as shown. A negative balance is sent with a minus sign. |

After a successful response, the page stays on the same mismatch list and reloads the report so that row updates. It does not apply a packing filter.

If the caller is not allowed, the API returns: **You do not have permission to adjust stock.**

Color key (shown under the totals):

| Color | Meaning |
|-------|---------|
| Red | DB stock is higher than ERP. Balance is positive. |
| Yellow | ERP stock is higher than DB. Balance is negative. |

### Create Deviation — qty display

The Create Deviation drawer shows three read-only pairs on one row. These numbers are for display only. They do not change the packing limit check, and they are not loaded on the packing list.

| Field | First number | Second number |
|-------|----------------|---------------|
| Schedule Qty / Balance Qty | Item schedule qty for the packing month (local plan, or IMS schedule when the month is not in the local table) | Schedule minus qty already on forwarding notes (same as Schedule Item Wise balance) |
| Shortage Qty / Balance Qty | Approved shortage for the item and month | Shortage minus qty already packed that month |
| FG Stock / Reorder Qty | Sellable in-hand FG | Reorder qty from the item master |
