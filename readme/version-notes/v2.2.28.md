- Backend list filters by `can_view_days` (created/submitted date window); update APIs reject edits outside `can_edit_days` (403).
- Frontend mirrors IMS: filter lists with view days; Edit toolbar / hotkeys / row open blocked when outside edit days (toast + disabled button).
- Shared helpers: `permissionDays.js` (FE + BE).

**Reflects:**
- Settings → user permissions → View days / Edit days (0 = unlimited)
- Task → CL Verification, CL Task Master, CL Task, Category, Holiday, Red Ticket, CL Task Report
