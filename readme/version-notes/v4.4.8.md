**Summary.** **IMS:** packing category **OEM Tray** (seed + helper mirror + sticker OEM fallback + Manage Tray as tray). **HRMS OT Approval:** default load shows all **Pending** OT with dates clear; optional From/To and Status (Pending / Approved / Rejected / All); quick filters tinted; future dates blocked; approve/reject unchanged (list reloads after decide).

| | |
