### Scan — Galat "Already scanned" error (sab IMS screens)

```bash
   Problem:
      Scan success ke turant baad camera same QR dubara padh leti thi → red "Already scanned" dikhta tha.
      Box add nahi hota tha, sirf galat error aata tha.
      Audit, Inward, Out Entry, QC Hold, Sticker Override — sab jagah same issue.

   Fix (4 second rule):
      Success ke 4 sec ke andar same box → silently ignore (camera re-read).
      4 sec ke baad same box scan → "Already scanned" dikhega.
      Scan process chal rahi ho → silently ignore.
      Real errors (wrong location, invalid QR) — pehle jaisa red error.

   Files:
      frontend/src/core/utils/scanSnackbar.js
      AuditExecutionModal.js, InwardModal.js, OutEntryModal.js,
      QcHoldMaterialModal.js, StickerOverrideModal.js
```

### Forwarding Note — Today Dispatch Plan

```bash
   Business rule:
      Same month ke items; due date aaj ya usse pehle; Plan + Hold include; Running exclude.
      Default filter: Plan + Hold.

   Row actions:
      Hold row → Reject + Reschedule (Complete nahi).
      Plan row → Complete + Reschedule.

   Row colors:
      Hold → red. Plan → green (FG stock >= Qty) / yellow (FG stock < Qty).

   Reject = soft update (status change). Delete = hard delete (rows physically remove).

   Files:
      ForwardingPage.js, TodayDispatchPlanTab.js
      schedulePlanService.js, schedulePlanDb.js
```
